## Datos
Se toman los datos del catálogo SPARC (*Spitzer Photometry & Accurate Rotation Curves*). Una base de datos de las curvas de rotación e información fotométrica de 175 galaxias espirales e irregulares con fotometría provista por Spitzer a 3.6 μm, en el infrarrojo cercano (NIR).
